# WhatsApp Gateway V1

Preservação independente da versão 1 do WhatsApp Gateway, separada da V2.

## Estado

O pacote original foi revisado para remover arquivos de configuração local que contêm credenciais e chaves. O código-fonte completo ainda precisa ser incorporado a este repositório; esta inicialização inclui apenas a documentação.

## Segurança

Nunca publique credenciais de banco de dados, tokens, segredos, chaves de instalação, arquivos `.env` ou configurações de produção.

## Pacote de origem

O arquivo preparado para importação é `whatsapp_gateway_v1_seguro.zip` (disponibilizado na conversa do ChatGPT), com a estrutura PHP, assets, banco de dados e documentação.
